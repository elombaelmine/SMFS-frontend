Troubleshooting Directory

Common system states and core operational guidelines.

How often is field data updated?

By default, the backend C++ daemon runs its data fetch operation every 2 minutes. This sync rate can be modified within your system settings panel.

What does the "Network: Stable" tag indicate?

It verifies that your application shell is successfully making handshake connections to the remote agricultural API servers with zero data drops.

How do I reset an emergency stop state?

Once an Emergency Stop command is issued, mechanical overrides must be verified locally. Refresh the application or toggle the switch interface to resume operations.
